Q1 Where from?
Quantitative attribution by region and sector — percentage from local sources, regional anthropogenic, biomass burning, dust.
via FLEXPART × EDGAR + GFED5
Q2 How will it evolve?
Regional 72 h trend plus incident-specific plume forecast for local emergencies with hourly footprint.
via CAMS + FLEXPART forward
Q3 What type?
Per-layer composition — fine/coarse mode, SSA, refractive index, type classification from research-grade inversion.
via GRASP + CAMS species
Q4 Where vertically?
Full vertical concentration and type profile with aerosol-layer altitudes and lidar-ratio-based discrimination.
via GRASP + ceilometer
Q5 Act or monitor?
Source-weighted, chemistry-aware action recommendation with incident-specific protocols and confidence.
via integrated decision logic
Q6 Scale of danger?
EU AQI five-level with multi-source validation flag — high confidence when RNMCA, AERONET, CAMS agree.
via RNMCA + AERONET + CAMS
