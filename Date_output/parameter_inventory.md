## Coordinate and time conventions

| Convention | Meaning |
|---|---|
| Earthaccess, EUMDAC, STAC bbox | West longitude, South latitude, East longitude, North latitude |
| CDS/ADS area | North latitude, West longitude, South latitude, East longitude |
| GeoJSON point / WKT vertices | Longitude, latitude |
| Station-based requests | Station ID replaces latitude/longitude in the shown query |
| Time | UTC where specified; ISO dates/timestamps unless separate fields are used |
